# Промт для ИИ-агента: генерация бота-ассистента для Max

Скопируй текст ниже целиком и передай его коммерческому кодинг-агенту (Claude Code, Cursor, и т.п.), чтобы он сгенерировал рабочий проект.

```
Разработай сервер чат-бота для мессенджера Max — персонального ассистента в групповом чате с тремя функциями: транскрибация и суммаризация голосовых сообщений, перевод сообщений, саммари обсуждения в чате.

## Технический стек
- Node.js + TypeScript
- Официальная библиотека Max Bot API: https://github.com/max-messenger/max-bot-api-client-ts (если библиотека недоступна или не подходит — работай напрямую с REST API)
- Express (или Fastify) для приёма Webhook
- SQLite (через better-sqlite3 или Prisma) для хранения истории сообщений — простое локальное решение, без внешней БД
- Anthropic SDK (@anthropic-ai/sdk) для LLM-функций (перевод, саммари, обработка транскрипций)
- Провайдер STT для голосовых сообщений (используй OpenAI Whisper API через обычный REST-запрос — ключ будет передан через переменную окружения)

## Интеграция с Max Bot API
- Базовый домен API: https://platform-api2.max.ru
- Авторизация: заголовок Authorization: <token> (токен бота берётся из переменной окружения BOT_TOKEN)
- Лимит запросов: 30 rps — добавь простой rate limiter на исходящие запросы
- Подписка на события — через POST /subscriptions, укажи HTTPS URL вебхука. В update_types обязательно включи получение обычных сообщений и bot_started
- Приём событий — реализуй Express-эндпоинт POST /webhook, который принимает объекты Update от Max
- Отправка сообщений в чат — через POST /messages
- Скачивание вложений (голосовых сообщений) — реализуй метод скачивания файла по ссылке из объекта сообщения перед отправкой в STT
- Webhook должен работать по HTTPS с валидным сертификатом (самоподписные сертификаты Max не принимает) — в README укажи, что для локальной разработки нужен туннель (ngrok/cloudflared) с валидным HTTPS
- Точная схема объектов Update, Message и методов — бери из официальной документации https://dev.max.ru/docs-api, не изобретай поля

## Логика бота

### Общая обработка входящих событий
1. Прими Update через вебхук
2. Определи тип: текстовое сообщение, голосовое сообщение (есть вложение с аудио), reply на сообщение с командой перевода, команда запроса саммари
3. Сохрани каждое текстовое сообщение (автор, текст, timestamp, chat_id) в SQLite — это нужно для функции саммари
4. Обработай по соответствующему сценарию (см. ниже) и отправь ответ в чат

### Режим 1 — голосовые сообщения
- Скачай аудиофайл через API Max
- Отправь в Whisper API для транскрибации
- Если длительность сообщения больше 30 секунд — дополнительно прогони расшифровку через Anthropic API с запросом на краткое резюме в 1-2 предложения
- Ответь в чат в формате:
  📝 Расшифровка: [текст]
  💡 Кратко: [резюме] (только если длиннее 30 сек)

### Режим 2 — перевод
- Триггер: reply на сообщение с текстом "переведи" или командой /translate
- Возьми текст исходного сообщения (на который сделан reply)
- Отправь в Anthropic API с промптом на перевод (автоопределение языка оригинала → русский, сохраняя тон и стиль)
- Ответь переведённым текстом без дополнительных пометок

### Режим 3 — саммари обсуждения
- Триггер: команда /summary [период] (например /summary 24h или /summary 50 — последние N сообщений)
- Достань нужные сообщения из SQLite по chat_id и периоду/количеству
- Отправь в Anthropic API с промптом на структурированное саммари по темам, с выделением явных договорённостей отдельным блоком
- Ответь результатом, обрезая по лимиту длины сообщения Max (если он есть — проверь в документации и обработай graceful, разбив на несколько сообщений при необходимости)

### Системный промпт для LLM-вызовов
Используй как system prompt для всех вызовов Anthropic API (адаптируй под конкретный режим — транскрибация/перевод/саммари):

---
Ты — персональный ассистент в групповом чате мессенджера Max. Твоя задача — помогать участникам чата экономить время и не терять важную информацию в потоке сообщений.
Пиши на русском языке, если не указано иное.
Форматируй ответы под мессенджер: короткие абзацы, умеренно эмодзи для структуры, без markdown-таблиц и сложной разметки.
Не упоминай, что ты языковая модель, если не спрашивают напрямую.
Уважай приватность: не сохраняй и не пересказывай личные данные (телефоны, адреса, финансовую информацию), маскируй их как [скрыто].
При неоднозначных или потенциально конфликтных ситуациях в чате — не занимай сторону, оставайся нейтральным.
---

## Структура проекта
Сгенерируй проект с примерно такой структурой:
- src/webhook.ts — приём и роутинг Update от Max
- src/maxClient.ts — обёртка над Max Bot API (отправка сообщений, скачивание файлов, подписка на вебхук)
- src/db.ts — работа с SQLite (сохранение и выборка истории сообщений)
- src/handlers/voice.ts — обработка голосовых
- src/handlers/translate.ts — обработка перевода
- src/handlers/summary.ts — обработка саммари
- src/llm.ts — обёртка над Anthropic API и Whisper API
- src/config.ts — чтение переменных окружения
- .env.example — с полями BOT_TOKEN, ANTHROPIC_API_KEY, OPENAI_API_KEY (для Whisper), WEBHOOK_URL, PORT
- README.md — инструкция по запуску: установка зависимостей, настройка .env, регистрация вебхука через POST /subscriptions, запуск локально через туннель для тестов

## Требования к качеству кода
- TypeScript strict mode
- Обработка ошибок на каждом внешнем вызове (Max API, Whisper, Anthropic) — бот не должен падать целиком из-за одной неудачной обработки сообщения
- Логирование входящих событий и исходящих ответов (простой consolе.log с timestamp достаточно для старта)
- Rate limiting на исходящие запросы к Max API (не больше 30 rps)
- Комментарии на русском языке в ключевых местах логики
```

## Как использовать

1. Скопируй блок в тройных кавычках выше — это сам промт для агента
2. Вставь в Claude Code, Cursor или другой кодинг-агент, добавив в начало путь к проекту или уточнив, что нужно создать новый репозиторий
3. Перед запуском агента подготовь заранее:
   - Токен бота (получишь после создания и модерации на [business.max.ru/self](https://business.max.ru/self))
   - API-ключ Anthropic
   - API-ключ OpenAI (для Whisper) или другой STT-провайдер
   - HTTPS-туннель для локальной разработки (ngrok, cloudflared) — Max не принимает самоподписные сертификаты и HTTP
